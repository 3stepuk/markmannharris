3.1 Origins of the New Code and Simplifying the Classic Code

By 1987, Grinder had begun collaborating with Carmen Bostic St. Clair, a business executive and NLP enthusiast who would become instrumental in developing New Code NLP. Bostic St. Clair had taken some of the original Meta Model patterns and applied them in corporate settings, experimenting with improving executive communication. In doing so, she made modifications and updates to the Meta Model that produced excellent results in her organizations (Welcome to the home of New Code NLP). She brought these findings to Grinder, which catalyzed the joint development of what we now call the New Code. According to an account on the New Code NLP website, “Bostic St Clair’s testing of the modifications and updates to the Meta Model paved the way for their future partnership, the recoding of Classic Code NLP and thus the emergence of New Code NLP… The first format was what is now called the Verbal Package; which Bostic St Clair had begun testing with her own execs when she was CEO.” (Welcome to the home of New Code NLP) (Welcome to the home of New Code NLP). In other words, the Verbal Package was the very first New Code pattern, born from tweaking the Meta Model for simplicity and effectiveness in real-world (non-therapy)

communication.

John Grinder’s motivations for creating the New Code were both practical and principled. He explicitly identified issues in the Classic Code that needed fixing, as he recounted in Whispering in the Wind:

“The motivations for the creation of the New Code are multiple and include a recognition that the coding of patterning I accomplished with Richard Bandler in the creation of NLP contained a number of serious coding flaws. In the late 70’s I noticed a significant number of NLP trained practitioners who were stunningly effective in doing change work with clients, yet these same practitioners had chosen to or lacked the choice to apply the patterns of NLP successfully to themselves. I, therefore, set out… to design a set of patterns that would both correct the coding flaws of the Classic Code… [and] could not be effectively presented unless the presenter was congruent with self-application.” (Welcome to the home of New Code NLP)

In this single statement, Grinder encapsulates the driving force behind New Code NLP:

For instance, the Meta Model had many categories and sub-questions; it’s possible to learn it by rote without grasping the essence. One flaw he noticed was indeed that lack of enforced congruence – one could teach the Meta Model without using it on oneself. Another possible flaw was complexity: the Classic Code offered many techniques and formats which could overwhelm or be misused by practitioners who didn’t have the experiential wisdom that the co-creators had.

Indeed, in another commentary, Grinder (and Bostic) describe their approach as moving “towards a reduced or minimal model – however one that is functionally equivalent to the full meta model.” . This minimalism is a hallmark of Grinder’s later work – focusing on high-leverage moves and not over-complicating. We see this in how the Verbal Package was constructed.

Alongside these goals, Grinder and Bostic recognized that Classic Code NLP overly emphasized conscious, content-level work. They observed that many classic interventions had the client consciously selecting new behaviors or analyzing their problem, which can be limiting. As an article on the evolution of New Code notes, “Another key issue [they] identified with Classic Code NLP was its excessive focus on the client’s conscious efforts to finding solutions… Grinder and Bostic recognized that the route to quick, deep, ecological change was dependent on the utility of the ‘unconscious mind’… In addition to utilizing resources from the unconscious, there is emphasis on intention and state at the level of input rather than changing behavior at the level of output.” (Welcome to the home of New Code NLP). In practice, this meant New Code patterns would involve things like evoking an optimal state in the client without discussing the problem content, utilizing unconscious signals for communication, and focusing on the underlying intentions of behaviors rather than the behaviors themselves.

How does this philosophical shift affect the Meta Model? Essentially, Grinder did not throw away the Meta Model’s linguistic precision, but he reframed its usage and pared it down to essentials. The outcome was the Verbal Package, which is the New Code’s streamlined equivalent of the Meta Model. The Verbal Package was designed to integrate seamlessly with New Code principles: it uses fewer questions, employs explicit framing of interactions, and incorporates some additional distinctions that encourage staying mindful of one’s intention and the level of description one is speaking at.

3.2 The Verbal Package vs. the Classic Meta Model

So what exactly is the Verbal Package? In simple terms, it is a slimmed-down Meta Model tailored for ease of use, especially in coaching or day-to-day communication contexts.

Michael Carroll, one of Grinder’s New Code colleagues, describes it succinctly:

“The Meta Model patterns are scaled down to challenge primarily noun and verb deletions.

Framing intention and paraphrase has been added to make the verbal challenges more user friendly, and to ensure the Practitioner is gathering correct information. This new model is called the Verbal Package.” (The Distinctive Features of New Code NLP - NLP Academy) (The Distinctive Features of New Code NLP - NLP Academy)

This description highlights key differences from the original Meta Model:

we enumerated earlier: unspecified nouns/pronouns, unspecified verbs, nominalizations, universal quantifiers, modal operators, cause-effect, mind-read, complex equivalence, lost performative, etc.).

The Verbal Package focuses on the most fundamental two: unspecified nouns and verbs, i.e.

simple deletions. Why these? Likely because recovering deletions yields the highest amount of lost information with the simplest effort. If you think about it, asking “Who specifically?” or “What specifically?” and “How specifically?” covers a lot of ground. Many of the distortion patterns in the Meta Model (mind reads, complex equivalences, etc.) can ultimately be addressed by asking for specifics too. For example, a mind read (“They think I’m stupid”) when challenged for specifics (“How do you know? Who specifically said that?”) often unravels. A cause-effect (“X makes me upset”) when challenged with “How specifically does X lead to that feeling?” forces a clarification of the mechanism or reveals it as an assumption. Thus, by prioritizing specifier questions – those that seek specific referents or processes – the Verbal Package covers most of the ground of the Meta Model with far fewer moving parts. It essentially teaches people a habit of clarifying the nouns and verbs in any important statement.

that the practitioner sets a context or positive frame around the questions they ask. Rather than a blunt interrogation (which early Meta Model users were sometimes guilty of, sounding like a linguistic drill sergeant), the New Code emphasizes explaining why you’re asking or what you’re aiming for. For instance, before diving into questions, a coach might say, “Let’s make sure I fully understand your goal here, because my intention is to help you get exactly what you need,” thereby framing the conversation with a shared outcome and positive intention. This makes the subsequent specific questions feel supportive rather than challenging the client in a negative way. It also involves checking the client’s intention: often, a New Code practitioner will explicitly ask about the intention behind a statement or a desire. For example, if a pregnant woman (to use a birth context scenario) says, “I don’t want any pain medications during labor,” a classic Meta Model approach might be to ask, “What are you afraid will happen if you do?” (challenging a possible generalization or fear). A New Code approach might start with, “I’d like to understand what’s most important to you about avoiding pain meds – what is your intention or goal with that?” This frames the inquiry around her positive intention (perhaps she wants to feel in control, or protect the baby’s alertness, etc.). By doing so, the conversation honors her values and makes any subsequent clarification feel collaborative. Grinder saw this as essential for ecology and rapport. It also ensures the practitioner is “gathering correct information” as Carroll notes – by clarifying intention, you ensure you don’t challenge something based on a false assumption.

Paraphrasing is a common active-listening skill in counseling, but here it’s explicitly part of the Verbal Package. For example, after eliciting specifics, one might paraphrase: “So, if I’ve got it right, you’re mainly afraid that if you accept pain relief you’ll feel like you failed, is that correct?” This gives the client a chance to confirm or correct the coach’s understanding. It’s an extra step that encourages precision (we got the info right) and rapport (“yes, you really hear me”). In the original Meta Model usage, practitioners did paraphrase or reflect sometimes, but it wasn’t highlighted as a distinct step – many early NLP demonstrations jumped straight from a question to the next question. The New Code codified paraphrasing as a way to slow down and ensure mutual understanding.

Grinder highlighting these terms suggests that in the Verbal Package, practitioners are trained to distinguish what kind of statement the client is making and respond appropriately. For instance, if a client’s statement is largely an interpretation or evaluation, the practitioner might lead them back toward a description (what actually happened) or at least recognize that more description is needed to verify the interpretation. This is similar to the Meta Model’s intent (uncover the actual experience behind generalizations or judgments), but it gives a clean way to talk about it without jargon. You can ask a client, “Is that an interpretation, or did it literally happen like that?” which is more everyday language than “That sounds like a complex equivalence.” Using these distinctions also encourages clients (and practitioners) to be mindful of their language: am I stating an observable fact, my interpretation of it, or my evaluation of it? All three have their place, but not disentangling them can cause confusion. For example, the simple phrase “He betrayed me” is actually an evaluation+interpretation built on some descriptive event. The Verbal Package would urge unpacking it: what did he do (description), what do you think it means (interpretation), and what are you feeling or judging about it (evaluation).

Functionally, these refinements make the Verbal Package a more conversational and user-friendly version of the Meta Model. It’s less about memorizing categories and more about following a few key steps:

In Classic Meta Model terms, that is similar to noticing when a client goes off on a tangent (which might be an avoidance) and bringing them back.

What’s notably absent in the Verbal Package is any overt challenge of the client or confrontation.

The tone is cooperative and curious rather than adversarial or “corrective.” One of Grinder’s critiques of how some early NLPers used the Meta Model is that they turned it into a blunt instrument, challenging clients in a way that made them defensive or feel dissected. By teaching framing and paraphrase, Grinder ensured the Verbal Package would be used in a softer, more collaborative manner.

It’s interesting to note that the Verbal Package was often taught implicitly through modeling in New Code trainings. Grinder and Bostic demonstrated it in how they interacted with students, sometimes without initially explaining the pattern. This was part of their emphasis on inductive learning. For example, they would consistently respond to trainees with specifier questions and reframe intentions, and the trainees would unconsciously pick up these speech patterns. One account states: “An excellent example of inductive learning is how Grinder and Bostic transferred the linguistic patterns from the New Code NLP ‘Verbal Package,’ through their verbal interactions with their corporate clients, who within a short period of time unconsciously demonstrated natural competence in utilizing patterns such as ‘intention frame’, ‘specifier questions’ and ‘paraphrasing’, all through natural modeling.” (Welcome to the home of New Code NLP). Only after the fact would they codify and explain the patterns that the learners had absorbed. This approach again underscores how New Code sought to engage the unconscious – teaching the Verbal Package not just as an intellectual model but as a natural way of speaking and listening.

3.3 Integrating the Verbal Package with New Code Principles

The Verbal Package was not an isolated tool; it was integrated into the wider New Code methodology. In Whispering in the Wind, Grinder and Bostic present a “Partial Listing of New Code patterning” which includes the Verbal Package among other patterns . For instance, if a client is practicing second position (seeing from another’s viewpoint), the coach can use specifier questions to deepen that (“What do you imagine specifically she feels when you say that?”). Also, the description–interpretation distinction helps avoid projecting one’s own evaluation when trying to truly see from another’s eyes.

However, before and after games, the Verbal Package can be used to frame outcomes (before the game, ensure what change the client wants, in simple terms) and debrief afterward (help the client put words to any change they experienced, again ensuring clarity without leading).

The idea is: do the change work at state level (game) then use the Verbal Package to language the change and connect it to real-life contexts. Grinder’s approach was often to get the change at an unconscious level then let the conscious mind understand in retrospect via some discussion.

The Verbal Package is the means to do this conversationally. A New Code practitioner will spend a bit of time with a client at the start of a session asking questions to define the desired outcome in positive, sensory-specific terms and to ensure that whatever change is pursued will honor the positive intention behind the current behavior and be ecological (no negative consequences). This is basically an applied Meta Model process focusing on goals. For example, if a client says “I want to stop procrastinating,” using Verbal Package one might ask, “What will you be doing when you are no longer procrastinating? (Outcome specificity), What’s important to you about not procrastinating? (Intention), Is there any part of you that benefits from procrastinating now? (to find intention behind the problem behavior), What might be the result if you suddenly became very proactive? (Consequence check).” These kinds of questions ensure clarity and set the stage for any change work. They echo the “Well-formed outcome” conditions taught in NLP, which themselves were an outgrowth of Meta Model thinking applied to goals.

The Verbal Package plays a role in handing over responsibility to the unconscious. Grinder mentions that in the new code, “the selection of the desired state, the resource, or new behaviors” is assigned to the unconscious . How does a practitioner do that in conversation? Often through verbal suggestion and framing. For instance, one might say to the client: “Your conscious mind doesn’t need to figure this out right now; we’ll let your unconscious generate the new alternatives while we play this game.” That is a framing statement (explicitly directing unconscious to take charge)

So the skill here is using language that communicates with the unconscious, which is actually the domain of the Milton Model (Ericksonian hypnosis language). Indeed, the New Code doesn’t discard the Milton Model; it uses it alongside the Verbal Package. Grinder intended the New Code practitioner to be artful in moving up and down the “spectrum of communication” – from very vague (Milton Model) to very precise (Meta Model) as needed. The Verbal Package covers the precise end, Milton Model covers the artfully vague end for unconscious elicitation.

The tone of a Verbal Package question coming from a know-nothing state is one of sincere curiosity, not challenge. For example, if a client says, “I just feel stuck,” a calibrated coach in know- nothing state might gently ask, “Stuck… I’m not sure I understand fully – what is it that you feel stuck about, specifically?” in a gentle tone, following any emotional cues of the client. This lands very differently than a matter-of-fact “What specifically are you stuck on?” delivered robotically.

Grinder’s New Code teaching emphasized quality of interaction over quantity of techniques.

All these integrations show that the Verbal Package, while a descendant of the Meta Model, is used in a more holistic way in New Code NLP. It’s embedded in a process that heavily features unconscious work, state work, and attention to relationship. Grinder himself writes that the New Code “focuses on the development of content-free, high performance states and their connection to the stimuli that define the context… The responsibility for the selection of… resources… [is] reassigned to the unconscious, thereby correcting some of the design flaws in the classic code.” . The design flaw in question was overly conscious selection – something the Meta Model in classic use might inadvertently encourage (since it requires conscious thought to answer the questions). By repositioning when and how the Verbal patterns are used, Grinder alleviated this: The Verbal Package is often used before the unconscious work (to frame and gather info) and after (to verify results and plan future action), but not to the exclusion of unconscious processing.

Grinder saw the Verbal Package as functionally equivalent to the Meta Model – it achieves the same end results (clear understanding, expanded maps, precise communication) – but in a much more elegant way. He and Bostic state, “Our own thinking is… quite different and moves towards a reduced or minimal model – however one that is functionally equivalent to the full meta model.” . This minimalist mindset is apparent in their teaching materials and books post-2000. They even implied that some extended Meta Model models proposed by others were unnecessary. Instead of adding more linguistic complexity, they stripped it down to a flexible package of essential skills.

In practice, experienced NLPers often used the Meta Model in a conversational way anyway. What Grinder did was codify that best practice and remove the need for the practitioner to explicitly think in terms of a dozen jargon-labeled categories. Instead of teaching “Here are 12 language patterns to memorize,” the New Code teaching is more like “Here’s how to listen for what’s missing or assumed, get the specifics, and always keep track of intentions and outcomes.” It’s a shift from analytic mode to mindful communication mode.

Grinder also intended the Verbal Package to be applied not just in formal “therapy” sessions, but in everyday influential communication. For example, a manager using it in meetings to clarify goals and issues, a parent using it to understand a child’s needs, a doctor using it to get accurate symptom information from a patient, and indeed a doula or childbirth educator using it to help a client articulate hopes and address fears (more on that in the next section). It is truly a portable skill set.

By 2001, Whispering in the Wind articulates the differences between Classic and New Code in no uncertain terms. The Meta Model (Classic) is acknowledged as a brilliant creation, but one that needed refinement. Grinder’s critique of the Classic Code is clearly laid out: in New Code, “1. The unconscious of the client is explicitly assigned the responsibility for selection of critical elements… 2. The unconscious is involved in all critical steps; 3. Precise constraints: new behaviors must satisfy original positive intentions; 4. Manipulation occurs at level of state and intention, as opposed to behavior.” . These points show how New Code elevates things like intention (which the Verbal Package explicitly incorporates with the intention frame) and state (which is handled by the games) and de-emphasizes direct behavior change conversation (which was often the domain of classic content-specific techniques).

Finally, Grinder often emphasized that New Code NLP is “simpler than Classic Code with better results” (The Distinctive Features of New Code NLP - NLP Academy). He used the metaphor that “New Code NLP is like a Ferrari… it’s fast, elegant, powerful.” (The Distinctive Features of New Code NLP - NLP Academy) The Verbal Package is one of the fine-tuned parts of that engine – elegant in that it achieves with a few questions what might previously have taken many, and powerful in that it improves communication in any context, not just formal change-work. Yet it’s important to note that “simpler” doesn’t mean “more superficial” – on the contrary, by integrating unconscious processes and focusing on key leverage points (like challenging deletions), New Code often addressed issues more deeply and efficiently.

For Grinder, this evolution was about returning to fundamentals – modeling excellence – and ensuring the models themselves were taught and used excellently. The Meta Model started as an explicit model of therapy excellence. The Verbal Package carries that torch forward, updated for the demands of a new generation of NLP where modeling one’s own behavior and achieving personal congruence are as important as influencing others.
